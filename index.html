Formulas and model parameters
L0 = −10.7976 + 0.8149·ln(TG) + 1.0250·ln(FPG) + 0.01607·waist + 0.2182·BMI + 0.01232·MAP − 0.1818·HDL p(MASLD) = 1 / (1 + e^(−L0)); positive if L0 ≥ −1.012 L1a: z = (AST/ALT − 1.1531) / 0.5638 p = 1 / (1 + e^(−(L0 − 0.0662 − 0.2906·z))) L1b = −13.6016 + 3.9291·ln(TG) + 5.4440·ln(FPG) + 0.2189·waist + 0.8958·BMI + 0.1350·MAP − 1.6359·HDL + 6.5549·ultrasound L2 (2-year risk, cause-specific): risk = 1 − exp(−H0·exp(lp − mean(lp))) CVD: lp = 0.0562·age + 0.0602·male + 0.1691·L0 CKD: lp = 0.0203·age + 1.4182·male − 0.0602·eGFR − 0.0303·Hb + 0.1435·WBC + 0.1960·L0 Liver: lp = 0.0420·age + 0.0464·male + 4.1518·APRI + 0.2822·ΔL0 Any: lp = 0.0559·age + 0.0649·male + 0.1685·L0 APRI = (AST/40) / platelets × 100; ΔL0 = current − previous L0 (0 if unknown)
Coefficients and baseline hazards are the frozen V12.1c estimates. L1b is a linear approximation of the CFA factor score (R² = 0.997) and is intended for severity quantification only.
MASpro V12.1c · verification-IPW derivation in TCCEF (n = 1,074,676) with external validation in NHANES and NAGALA. Values are estimates for research use; they do not replace clinical judgement.
