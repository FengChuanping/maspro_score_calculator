# MASpro Score Calculator

**Open the calculator: https://fengchuanping.github.io/maspro_score_calculator/**

A single-file web calculator for the MASpro layered score: MASpro-L0 (six-item core score), MASpro-L1a (non-imaging add-on), MASpro-L1b (imaging quantification) and MASpro-L2 (1-3-year progression risk).

All coefficients and baseline hazards are the frozen V12.1c estimates. Research tool; not a substitute for clinical judgement.
